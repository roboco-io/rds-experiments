## 확인할 질문

DSQL에서 같은 업무를 구현하려면 무엇을 바꿔야 하는가?

## 측정 결과

2026-09-24 UTC에 Claude Agent SDK와 Claude Opus 5.5로 실측을 시작했습니다. DSQL → RDS PostgreSQL → Aurora Provisioned → Aurora Serverless v2 순으로 각 구성을 검사·삭제합니다. 현재 결과를 수집 중이며 검토 전 수치로 결론을 내리지 않습니다. 이번 E001은 로컬 클라이언트와 소형 구성의 SQL 기능 검사이며 처리량·지연·고가용성 벤치마크가 아닙니다.
